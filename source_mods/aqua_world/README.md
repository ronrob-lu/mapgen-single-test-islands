# Aqua World

Aqua World is a simple Luanti worldgen mod that creates a clean underwater world made of water, sand, and sandstone.

## Description

Aqua World gives you a calm aquatic environment with:

- a deep water layer
- a sand seabed
- a sandstone base layer

## Requirements

This mod depends on the `default` mod and uses:

- `default:water_source`
- `default:sand`
- `default:sandstone`

## Notes

Aqua World is intentionally simple.

It is designed to create a flat ocean-style world, not a complex biome or terrain system.
